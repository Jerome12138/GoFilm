### 关键决策

1. **preset-icons 暂时禁用**：unocss 0.62.4 + @iconify-json/carbon 1.2.5 在 build 阶段会输出非法 CSS（`Missed semicolon` 错误）。改用 BaseIcon 组件的 inline SVG 集合托底。后续 story 可考虑升级 unocss 至 ^0.65 或换用 unplugin-icons。
2. **TV 模式样式分块写法**：所有 `:global([data-mode='tv']) .xxx` 写法在 Vue scoped style 中不被识别，改为在同一 SFC 末尾追加一个 unscoped `<style>` 块写 `[data-mode='tv'] .xxx`。
3. **arbitrary value 谨慎使用**：`ease-[var(--gf-ease-standard)]` 这类 unocss preset-uno 无法解析的 token 已替换为 `<style scoped>` 中的 transition 写法。
4. **触控命中区**：所有 button 类元素 min-height ≥ 44px，sm 尺寸通过外层 padding 补足而非缩小命中区。
5. **路由跳转**：FilmCard / HeroCarousel CTA 全部走 `<RouterLink :to="{path,query}">` 或 `router.push`，绝不裸跳。

### 后续 view 开发注意事项

1. **图标先看 BaseIcon 集合**：缺图标时优先扩 `BaseIcon.vue` 的 PATHS map（保持 24×24 viewBox，单色填充），不要再用 `i-carbon-xxx` / `i-mdi-xxx`，build 会失败。
2. **API 调用绝不在组件内**：film/ 内组件只接受 props 渲染，所有 axios 调用集中在 view + `api/`，详情见 `doc/handover/03-arch-handover.md`。
3. **TV 模式样式**：组件内的 TV 差异化必须放在末尾的 unscoped `<style>` 块（写 `[data-mode='tv'] .xxx`），不能写在 scoped 块的 `:global()` 里。
4. **卡片列宽 / Row gap / 集数列数** 已按 `components-spec.md` 落到 CSS，view 不需要重新覆盖。
5. **BaseButton 的 size=lg/xl** 默认走 44px 触控命中区；HeroCarousel 中 CTA 已用 `lg` 尺寸示范。
6. **真实数据接入**：`HomeView` mock 数据结构与 `IndexPageData` 对齐（FilmListItem[]），STORY-008 直接替换数据源即可，无需改组件。
